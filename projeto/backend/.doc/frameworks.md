# Frameworks e Bibliotecas

Este projeto utiliza os seguintes frameworks e bibliotecas para melhorar a produtividade e a manutenibilidade:

## **.NET 8.0**
- Framework principal para desenvolvimento da API.
- Suporte a APIs RESTful e middleware.

## **Entity Framework Core**
- ORM para mapeamento de entidades e acesso ao banco de dados.
- Suporte a banco de dados em memória (`InMemoryDb`) para testes e execução local.

## **MediatR**
- Implementação do padrão Mediator para comunicação entre componentes.
- Facilita a separação de responsabilidades e a manutenção do código.

## **AutoMapper**
- Biblioteca para mapeamento de objetos.
- Reduz a necessidade de código repetitivo ao mapear entidades para DTOs.

## **Serilog**
- Biblioteca para logging estruturado.
- Permite rastrear eventos importantes no sistema.

## **Swagger**
- Ferramenta para documentação e teste interativo da API.
- Facilita a exploração dos endpoints disponíveis.
