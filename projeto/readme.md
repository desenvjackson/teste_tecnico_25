# README Técnico 

## Visão Geral

Este projeto é o frontend do sistema **DeveloperStore**, desenvolvido em **React** e consumindo uma API REST configurada no arquivo `apiClient.js`. Antes de iniciar o frontend, é necessário garantir que o backend esteja ativo e configurado corretamente.

---

## Configuração do Backend

O backend é responsável por fornecer os dados consumidos pelo frontend. Certifique-se de que o backend está configurado e rodando antes de iniciar o frontend.
Leia o readme da pasta backend, para subir o serviço.
