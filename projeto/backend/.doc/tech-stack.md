# Pilha de Tecnologia

Este projeto utiliza as seguintes tecnologias e ferramentas:

## **Back-End**
- **.NET 8.0:** Framework principal para desenvolvimento da API.
- **Entity Framework Core:** ORM para mapeamento de entidades e acesso ao banco de dados.
- **InMemoryDb:** Banco de dados em memória para simplificar a execução e os testes.

## **Testes**
- **xUnit:** Framework para criação de testes unitários.
- **Moq:** Biblioteca para criação de mocks em testes.
- **FluentAssertions:** Biblioteca para melhorar a legibilidade das asserções nos testes.

## **Documentação**
- **Swagger:** Ferramenta para documentação e teste interativo da API.

## **Outras Ferramentas**
- **Serilog:** Biblioteca para logging estruturado.
- **AutoMapper:** Biblioteca para mapeamento de objetos.
- **MediatR:** Biblioteca para implementação de padrões de comunicação entre componentes.
